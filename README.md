# UINSPIRE – Empowering the Future with Technology 🚀

Hey there! Welcome to the source code for the **UINSPIRE** corporate website. 

UINSPIRE is a technology consulting firm, and this project serves as our digital home. We wanted a web presence that feels as modern, robust, and forward-thinking as the solutions we build for our clients. 

This repository contains the complete, 12-page corporate website designed to showcase our services, team, portfolio, and vision.

## What's Inside? 📦

Instead of relying on heavy UI frameworks, we decided to build this completely from the ground up using a handcrafted design system. It gives us maximum flexibility and ensures the site is lightning-fast and highly accessible.

* **12 Fully Responsive Pages**: Everything from the home page, about us, services, blog, careers, down to the privacy policies and terms of service.
* **Custom Design System**: Beautiful, consistent aesthetics featuring sleek dark/light mode adaptations, glassmorphism touches, and smooth micro-animations.
* **Vite under the hood**: For a fast and optimized development and build experience.

## Tech Stack 🛠️

Keeping it clean and simple:
- **HTML5** for semantics and structure
- **Vanilla CSS3** for custom, unopinionated styling
- **Vanilla JavaScript** for interactive elements and DOM manipulation
- **Vite** as our frontend tooling for lightning-fast hot module replacement and optimized production builds.

## Getting Started 💻

Want to run this locally or tinker around? It's super straightforward.

1. **Clone the repository**
   ```bash
   git clone https://github.com/Olamide7/UINSPIRE-Project.git
   cd UINSPIRE-Project
   ```

2. **Install the dependencies**
   ```bash
   npm install
   ```

3. **Spin up the development server**
   ```bash
   npm run dev
   ```
   *Vite will automatically open the site in your default browser, or you can visit `http://localhost:5173`.*

4. **Build for production**
   ```bash
   npm run build
   ```
   *The optimized, minified files will be generated in the `dist` folder.*

## Why We Built It This Way 🤔

We believe your company's website is its digital handshake. By keeping our tech stack minimal and relying on pure web standards, we eliminated unnecessary bloat. It's easy to maintain, scalable, and performs brilliantly across all devices and network conditions.
